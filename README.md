# Bringing Modern Technology to Classic Cars

This project showcases a customizable **automotive tail-light system** built with an **Arduino Nano**, **WS2812/SK6812 addressable LEDs**, a **TFT ILI9341 display**, and two **MCP2515 CAN modules**.

## Goal
Develop a set of configurable tail lights that can be controlled through a modernized on-board computer displayed on the TFT screen.

## Key Features
- **Full lighting control**: adjust brightness, animations, and light frequency.
- **Special modes**: dynamic turn-signal effects and a “show mode” for visual effects.
- **Vehicle-button integration**: navigate the menu using the car’s existing control buttons.
- **Extended compatibility**: SK6812 LED support via a FastLED library extension.

## Technical Highlights
- Hardware integration of all components.
- Level-shifting to solve voltage-compatibility issues between the TFT and Arduino.
- Reliable CAN communication using MCP2515 modules for robust control.

## Outcome
The project demonstrates how modern electronics can significantly enhance the functionality and aesthetics of classic vehicles, bringing them closer to today’s standards of comfort and personalization.
